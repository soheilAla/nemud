نمود یه قالب برای ساخت سریع رزومه‌های حرفه‌ایه که با تمرکز روی خوانایی و ساختار ATS-friendly طراحی شده.

به‌جای درگیر شدن با انتخاب فونت، اندازه و تنظیم فاصله‌ها یا نگرانی راجع به سازگاری با ATS، کافیه اطلاعاتت رو توی یه فایل JSON وارد کنی. نمود بقیه کار رو انجام می‌ده.

## ⁉️ مشکل چی بود؟

اکثر رزومه‌سازها و تمپلیت‌ها آزادی زیادی برای تغییر ظاهر رزومه بهت می‌دن. اما این آزادی همیشه به ساخت یه رزومه بهتر منجر نمی‌شه.

استفاده از عنوان‌های غیرمعمول، تغییر نامناسب قالب صفحه و شخصی‌سازی‌های غیراصولی استفاده از عنوان‌های غیرمعمول، تغییر نامناسب قالب صفحه و شخصی‌سازی‌های غیراصولی به شکل ناآگاهانه، می‌تونن خوانایی رزومه رو کاهش بدن و کار سیستم‌های ATS رو برای خوندن و استخراج اطلاعات سخت‌تر کنن.

## ✨ ویژگی‌ها

- استفاده از طراحی ثابت با فونت، رنگ، فاصله‌‌ها و اندازه حاشیه اصولی برای یکدستی و خوانایی حداکثری
- استفاده از چیدمان ساده و تک‌ستونه برای خوانایی بهتر و حفظ ترتیب اطلاعات هنگام استخراج توسط ATS
- نوشتن و ویرایش راحت تمام اطلاعات رزومه از طریق فایل JSON
- امکان مخفی کردن بخش‌های مختلف رزومه و تغییر ترتیب نمایش اون‌ها
- اعتبارسنجی اطلاعات واردشده بر اساس Schema

## 🚀 راهنمای استفاده

### اجرای لوکال

بعد از نصب Node.js و pnpm:

```
git clone https://github.com/soheilAla/nemud.git
cd nemud
pnpm install
pnpm dev
```

آدرسی که توی ترمینال نمایش داده می‌شه رو با مرورگر باز کن تا خروجی زنده رو ببینی (احتمالاً [http://localhost:4321](http://localhost:4321)).

### ویرایش اطلاعات رزومه

اطلاعات رزومه توی فایل `config/cv.json` قرار می‌گیرن.

فیلدهایی که می‌تونی استفاده کنی و قوانین مربوط به هرکدوم، توی فایل `config/cv.schema.json` تعریف شدن.

### تنظیم ترتیب یا نمایش بخش‌ها

از طریق فایل `config/site.json` می‌تونی بخش‌های مختلف رزومه رو مخفی کنی یا ترتیبشون رو تغییر بدی.

### تصویر پروفایل

تصویر رو داخل پوشه `config/` قرار بده و مسیرش رو توی فیلد `basics.portrait` از فایل `cv.json` بنویس.

### فرمت متن

برای Bold کردن بخشی از متن، اون رو بین دو `**` قرار بده:

```json
{
  "summary": "You can bold **important text** with double asterisks."
}
```

### دریافت خروجی PDF

```
pnpm build
pnpm preview
```

توی مرورگر رزومه رو به عنوان PDF پرینت کن (`CTRL + P` و انتخاب Save to PDF به عنوان Destination).

حواست باشه گزینه `Print headers and footers` غیرفعال باشه که اطلاعات اضافی مرورگر توی خروجی نمایش داده نشه.

## ⚠️ درباره سازگاری با ATS

‏ATS (Applicant Tracking System) نرم‌افزاریه که شرکت‌ها برای مدیریت درخواست‌های استخدام ازش استفاده می‌کنن. نمود با هدف ساخت رزومه‌های قابل‌پردازش برای این سیستم‌ها طراحی شده.

اما ATSها از روش‌های مختلفی برای بررسی رزومه‌ها استفاده می‌کنن؛ پس هیچ قالبی نمی‌تونه سازگاری 100 درصدی با همه اون‌ها رو تضمین کنه.
